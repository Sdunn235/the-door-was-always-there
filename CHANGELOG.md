## [0.1.0] - 2026-11-03

Phase 0, setup (commit C0001).

### Added
- The project is its own git repository. Private planning notes are excluded from it.
- The game can be built as **one file** (`dist-single/the-door-was-always-there.html`) that opens by double-click and plays with no internet.
- A temporary test page (a small room on a canvas and a button that moves a circle) to prove that file works offline.
- Automated tests run with `npm test`.
