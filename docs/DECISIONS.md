# Decisions

One place for every choice that shapes the project: what was decided, why, and when to revisit it.

**Statuses:** **Approved** (Shawn decided) · **Provisional** (Claude's working default; Shawn can change it any time) · **Needs Shawn** (blocked on Shawn; a placeholder is used until then)

To decide a **Needs Shawn** item: write the answer in its row, change the status to Approved, add the date, and move the row up to the Approved table.
